# UI reference v2 implementation

The user-supplied LongySinc_App_UI_v2.html is a visual reference. Its example measurements and product claims are not live user data.

Implemented warm cream, forest green, rounded cards and softer typography throughout the Flutter theme. Main navigation is Today, Trends, central quick log, Sinc and You; desktop retains a navigation rail. Today uses saved daily totals and a seven-day record coverage dial. Trends connects existing timestamped charts to metric and period selectors. Sinc shows local summaries with selectable questions. You provides profile editing and vault links. Quick log opens existing validated, persisted entry forms. Wearables and Add ring remain accessible.

Retained LongiSync branding and the generated launcher logo. The companion uses a code-drawn gradient orb. No biological-age estimates, example correlations, clinician signatures, voice recognition, marketplace transactions or chamber controls are represented as working features. Those additional reference concepts require separate services/integrations. Mini Zone hardware compatibility still needs testing on the actual ring. Health records currently persist locally; they are not synchronized to a production backend.

Validation: Flutter analysis and 15 tests pass, including light/dark layouts at 320, 393 and 1024 pixels, authentication navigation and persisted meal entry. Android debug version 1.2.0+3.
